# ШИФРОПАНК // NETRUNNER TERMINAL

Браузерная пошаговая игра про нетраннеров для игры с друзьями по локальной сети (Radmin VPN).

---

## 1. Установка и запуск (у хоста)

1. Установите **Node.js** версии 18 или новее: https://nodejs.org
2. Откройте терминал (cmd/PowerShell) в папке проекта и выполните:

```bash
npm install
npm start
```

3. Сервер запущен. У себя открывайте: **http://localhost:3000**

> Новичкам: на экране входа есть кнопка **«ПРАВИЛА»** — подробное описание механик и всех программ (тот же текст лежит в `public/rules.html`, можно кинуть друзьям заранее).

## 2. Как подключиться друзьям через Radmin

1. Все игроки (включая хоста) должны быть в одной сети **Radmin VPN**.
2. Хост смотрит свой IP в Radmin (например, `26.12.34.56`).
3. Друзья открывают в браузере: **http://26.12.34.56:3000** (подставьте свой IP).
4. Если не подключается — разрешите Node.js в брандмауэре Windows или временно его отключите.

### Комнаты

На одном сервере может идти несколько партий сразу. Кнопка **«СОЗДАТЬ ИГРУ»** поднимает новую комнату — вы её хост. Сервер покажет **код комнаты** (4 символа) — продиктуйте друзьям или пришлите ссылку вида `http://26.12.34.56:3000/?room=КОД`. Остальные жмут **«ПОДКЛЮЧИТЬСЯ»**, введя позывной и код. Комнаты полностью изолированы (лобби, матч, чат, **радио-плеер** — у каждой комнаты свой эфир: что включили в одной комнате, не слышно в другой); общими остаются только плейлист (загруженные файлы) и новости. Опустевшая комната удаляется сама.

> Порт можно сменить: `set PORT=8080 && npm start` (Windows) или `PORT=8080 npm start` (Linux).

### Игра с телефона

Если сервер доступен по сети/интернету, с телефона просто откройте тот же адрес в браузере — интерфейс сам перестроится под мобильный: карта во всю ширину, панели друг под другом, крупные кнопки и слоты. Перетаскивание на сенсоре заменяется тапами: **тап по программе → тапы по слотам** (нужная комбинация написана в подсказке) → программа разыгрывается сама, когда набрано нужное число слотов; повторный тап по карте — отмена. Цель на карте выбирается тапом, как обычно. **Долгий тап** по карте руки (полсекунды) открывает её полноэкранно — с полным описанием эффекта (обычный тап остаётся взведением карты). Рука прокручивается **свайпом пальца** по полосе карт (в режиме «СПИСОК» — обычной прокруткой). Боковые панели (чат, игроки, радио) на телефоне скрыты: их открывает кнопка **☰ ПАНЕЛИ** в верхней строке — поверх экрана, повторный тап закрывает. Чуть выше карты — **полоса хода** (кто сейчас ходит): тап по ней открывает окно со списком всех игроков, их ХП и мощностью. Для скорости на слабых телефонах тяжёлые эффекты (CRT-сканлайны, мерцание и вращение объектов карты, glow-тени) автоматически отключены. Змейка на телефоне управляется **свайпами по игровому полю** (жест «потяни вниз» браузера заблокирован — страница не перезагрузится посреди партии). Пиксели игроков на карте укрупнены (клетка не мельче 12px). **Если связь оборвётся** (телефон уснул, сеть моргнула) — перезаходить не нужно: игра сама восстановит соединение и вернёт вас в комнату под вашим позывным; пустая комната ждёт возвращения 10 минут. Выйти насовсем — кнопка «ВЫЙТИ ИЗ КОМНАТЫ» в лобби. Для телефона удобнее всего дизайн руки «СПИСОК» (🎨 ВИД).

## 3. Ход игры

1. **Лобби.** Все вводят позывные. Игрок попадает в матч только по собственному «ГОТОВ» — чужие нажатия никого не «затаскивают» в игру. Любой игрок может менять параметры сессии (режим игры, командный режим, ХП, мощность, размер руки, таймер, размер карты, антивирус — см. 3.7) — при изменении готовность всех сбрасывается (общее согласие). **Таймер 0 = таймер отключён совсем** (кнопка паузы прячется, вместо отсчёта — ∞). Когда все нажали «ГОТОВ» (минимум 2 игрока) — начинается подготовка. У хоста есть кнопка **«⟳ ПЕРЕСОЗДАТЬ ИГРУ»**: вся комната сразу уходит в новую подготовку, минуя круг нажатий «ГОТОВ» (удобно после матча — никто не зависает в AFK).
2. **Подготовка** идёт по шагам:
   1. Каждый выбирает интерфейс (класс) и цвет пикселя → «ДАЛЕЕ» (повторный клик/тап по уже выбранному классу работает как «ДАЛЕЕ» — удобно с телефона).
   2. **Хост настраивает карту** (стены, зоны, мины, порталы, заливка прямоугольником, очистка; ПКМ — удалить объект), остальные видят экран загрузки. Редактировать карту может **только хост**.
   3. Хост жмёт «КАРТА ГОТОВА» — и только теперь все (включая хоста) **собирают руку программ** → «ГОТОВ». **Дубликаты программ в руке запрещены.**
   4. Когда все собрали руки — расстановка: каждый ставит персонажа на карту (ЛКМ). Если хост поставил **пиксели спауна** (⦿), ставиться можно только на них (одна клетка — один игрок).
   5. Когда все поставили пешки — матч начинается автоматически.
3. **Матч.** В начале вашего хода генерируются слоты (по числу мощности) со случайными 0/1. Перетащите программу из руки на слоты: подсвеченные зелёным слоты должны совпасть с потреблением программы. Если программе нужна цель — кликните по клетке/врагу на карте (Esc — отмена). Программа возвращается в руку, слоты закрываются.
4. **Конец хода.** Кнопка «ЗАВЕРШИТЬ ХОД» или таймер. За каждый незакрытый слот вы получаете 1 урон. ХП = 0 — смерть мозга. Погибший не вылетает из матча: кнопка **«📡 НАБЛЮДАТЬ ЗА ИГРОЙ»** на экране смерти закрывает его — бой идёт дальше перед глазами, а карта, канал и радио (включая загрузку своих треков) остаются доступны. В режиме «Перестрелка» побеждает последний выживший (в командном режиме — последняя живая команда). В режиме «Захват территории» — первый, кто набрал нужное число очков (см. 3.1).

> **Пауза таймера.** Кнопка ⏸ рядом с таймером (вверху) ставит отсчёт на паузу / снимает её — на случай, если кто-то отошёл (AFK). Работает для всех одновременно.
>
> **Настройки вида (кнопка 🎨 ВИД).** В шапке боя и на экране входа. Всё локально — сохраняется в браузере и действует только на вас:
> - **Цвет интерфейса:** ЗЕЛЁНЫЙ / ЯНТАРЬ / ЛЁД / УЛЬТРА / ТЕРМИНАЛ (белое на чёрном).
> - **Размер интерфейса:** КОМПАКТНЫЙ / ОБЫЧНЫЙ / КРУПНЫЙ. КРУПНЫЙ — не просто масштаб, а другая компоновка: рука встроена в раскладку отдельной полосой под слотами, поэтому карты гарантированно не накрывают ни слоты, ни карту сектора.
> - **Дизайн руки:** ВЕЕР (вращающаяся дуга), КЛАССИКА (старый плоский ряд из 9 карт со стрелками ◂ ▸ и счётчиками), СПИСОК (все программы в рядок с прокруткой).
> - **Размер карты:** ползунок 50–200% — масштаб клеток самой карты: 100% — карта целиком влезает в окно, больше — клетки крупнее, а карта прокручивается внутри окна.

## 3.1 Режимы игры и команды

**Режим игры** выбирается в лобби:

- **ПЕРЕСТРЕЛКА** — классика: побеждает последний выживший.
- **ЗАХВАТ ТЕРРИТОРИИ** — хост ставит на карте точки контроля (◈, нужна минимум одна). Стоя на точке, вы держите программу **КодШифр** — она существует только пока вы на точке и показывается отдельно от руки (жёстко закреплена в левом нижнем углу экрана — под сайдбаром, левее веера руки). Её потребление (и комбинация, и длина) перешифровывается каждый раунд; диапазон длины задаётся в лобби. Разыграли КодШифр, стоя на точке, — **+1 очко**. Набрали нужное число очков (задаётся в лобби) — победа. Сошли с точки — карта исчезает. **Рост КодШифра** (настраивается в лобби): потребление удлиняется на N бит за каждые K уже набранных очков — чем больше у вас (или вашей команды) очков, тем сложнее взять следующее. **Командные точки:** у точки контроля есть владелец («чья точка» в редакторе: любая / А / Б / В / Г). В командном режиме захватить можно только свою или нейтральную точку — буква команды рисуется в углу клетки. Хотите «захват точки на базе врага» — поставьте точку команды А на базе команды Б. У каждой участвующей команды обязана быть доступная точка — иначе карту не примут.

**Командный режим** (галочка в лобби): каждый игрок сам выбирает себе команду в лобби (цветной селектор у ника). Команд должно выйти минимум две — иначе «ГОТОВ» не сработает. Побеждает вся команда целиком. **Дружественный огонь не отключается**: урон по площади, выкачивание мощности и толчки задевают и союзников. Одиночка без команды считается «командой из одного».

## 3.2 Режим отладки

Секретный режим для тестирования игры в одиночку:

- **Включение:** невидимая кнопка в **правом нижнем углу экрана входа** (где вводится позывной — подведите курсор в угол, там зона 34×34 px). Появится тост-подтверждение; режим активируется автоматически при подключении.
- Матч можно начать **в одиночку** (без второго игрока).
- На экране руки появляется кнопка «ВСЕ ПРОГРАММЫ» — берёт сразу все 30 программ (лимит руки снимается; служебный КодШифр не входит).
- В бою появляется красная панель ОТЛАДКА: изменение своих ХП и мощности кнопками −/+, переброс слотов, завершение чужого хода.
- **Клик по открытому биту слота** (в своей панели слотов) переворачивает его 0↔1.
- Режим действует только на того, кто его включил; если отладка включена хотя бы у одного игрока — минимум для старта снижается до 1.

## 3.3 Инструменты хоста для карты

На шаге настройки карты у хоста есть панель инструментов:

| Инструмент | Что делает |
| --- | --- |
| **СТЕНА** | Непроходимый битый пиксель (мерцает глитч-символами). Блокирует движение и линию видимости. |
| **ЗОНА** | Проходимая клетка с эффектом в начале хода стоящего на ней: нет / лечение / урон / +мощность / телепорт. Можно запретить проход (walkable). |
| **МИНА** | Взрывается, когда кто-то наступает **или проходит сквозь неё** (путь движения проверяется по клеткам — «проскочить» мину нельзя; это же работает при отталкивании «Пинг-понгом»): урон (по умолчанию 5), мина исчезает. Поставить мину на клетку с игроком нельзя. |
| **ПОРТАЛ** | Телепортирует наступившего в случайную свободную клетку в заданном радиусе (0 — вся карта). |
| **ПОРТАЛ ПАРНЫЙ** | Оранжевый ◉ с номером пары в углу. Порталы с одинаковым номером связаны: вход в один переносит на случайную свободную клетку в радиусе 1 вокруг второго (не на сам портал); если все соседние клетки заняты — вход не срабатывает: игрок получает ошибку, остаётся на месте, а потраченные на программу передвижения слоты возвращаются. Каждый номер пары обязан быть ровно в двух экземплярах — иначе карту не принять. |
| **ТОЧКА КОНТРОЛЯ** | ◈ для режима «Захват территории». В этом режиме без точки карту не принять. Параметр «чья точка»: любая (нейтральная) или команда А/Б/В/Г — в командном режиме чужую точку захватить нельзя; буква команды видна в углу клетки. |
| **РАЗЛОМ ДАННЫХ** | ⌁ Вступивший видит окно: можно ОДИН раз поместить в разлом программу из руки — она станет сломанной (выбираете, какой бит потребления убрать; сломанная бьёт владельца на 2 ХП при каждом использовании). Для каждого игрока разлом срабатывает отдельно. |
| **ПИКСЕЛЬ СПАУНА** | ⦿ Стартовая клетка. Если на карте есть хотя бы один — в начале матча пешки ставятся только на спауны (спаунов должно быть не меньше, чем игроков, иначе карту не примут). Без спаунов расстановка свободная. |
| **ЛАСТИК** | Стирает объект с клетки (работает и с зажатой ЛКМ). |
| **Время жизни** | У любого объекта: 0 — навсегда, N — исчезнет через N раундов. |
| **Прямоугольник** | Галочка «ПРЯМОУГОЛЬНИК»: клик по двум углам заливает область выбранным объектом. |
| **Зеркало** | Каждая установка отражается по горизонтали (↔), вертикали (↕) или обеим осям (✚) — удобно для симметричных карт. |
| **Рисование** | Зажмите ЛКМ и ведите по карте — объекты ставятся/стираются серией. Вся серия отменяется одной кнопкой ↩ ОТМЕНА. |
| **СТЕНЫ ПО КРАЯМ** | Рамка из битых пикселей по периметру карты одним нажатием. |
| **ОЧИСТИТЬ** | Удаляет все объекты с карты. |

ПКМ по объекту — удалить. У каждого объекта настраиваются имя и цвет. У каждого инструмента есть описание прямо в панели, пресеты (ХАОС/АРЕНА/ЛАБИРИНТ/ОСТРОВА) заменяют всю карту, шаблоны сохраняются в браузере хоста.

## 3.4 Рука, слоты и карта в бою

- **Рука — на выбор три дизайна** (кнопка 🎨 ВИД, у каждого свой): веер-дуга, классический ряд со стрелками или простой список с прокруткой. По умолчанию — **зацикленный веер карт** (как в Hearthstone): парит поверх низа экрана по центру, одновременно видно до 9 карт. Карты стоят на дуге с фиксированным шагом, и чем дальше карта от центра — тем сильнее она завёрнута, ниже, мельче и прозрачнее. У руки нет краёв: веер **зациклен** и бесконечно вращается **колёсиком мыши** или **стрелками ← →** (вращение работает, когда карт больше трёх) — за последней картой снова идёт первая; карты при прокрутке плавно проворачиваются по дуге. Наведение — карта приподнимается и увеличивается прямо в руке (в крупном интерфейсе подъём остаётся внутри полосы руки и не задевает слоты). В дизайне «СПИСОК» вместо подъёма полноразмерная копия карты с полным описанием всплывает отдельным окном в правом нижнем углу. Фиксированные «слоты-hitbox'ы» между картами убирают мерцание переключения. У каждой карты полупрозрачный принт по типу программы, крупное потребление и короткое описание эффекта; полный текст — во всплывающей подсказке при наведении.
- **Сломанные программы** видны прямо в руке: карта мерцает красным глитчем. Ломаются они в **разломе данных** (см. 3.3): минус один бит потребления, но −2 ХП при каждом использовании.
- **КодШифр** (режим захвата) живёт отдельно от руки — жёстко закреплён в левом нижнем углу экрана, под сайдбаром и левее веера руки (больше не надо двигать руками после обновлений); тянется на слоты так же, как обычная программа.
- **Слоты** — квадратные, под картой, рядом с программами. 0 и 1 выглядят полностью одинаково (отличается только цифра). У закрытого слота цифра исчезает — остаётся только символ ✕ (или ⇄ у корпоративного интерфейса).
- **Слоты — личные.** Полоску слотов видит только тот, чей сейчас ход (у остальных там плашка «слоты появятся в начале вашего хода»). Подсмотреть чужие слоты можно только в очереди игроков слева — они показаны у активного игрока.
- **Кустарный интерфейс** — раз за свой ход клик по одному открытому биту слота переворачивает его (0↔1) ценой 1 ХП; перевёрнутый бит глитчит до конца хода.
- **Матричный интерфейс** — **СТАВКА**: раз за свой ход, ДО розыгрыша любой программы (и до переворота бита), можно поставить на кон одну свою целую программу с потреблением от 2 бит: перетащите её в плавающее пунктирное окно «МАТРИЦА» — в обычном/компактном интерфейсе оно справа от карты, в крупном — справа у полосы руки (на телефоне окна нет: долгий тап по карте → кнопка «🎰 СТАВКА»). Слоты прокручиваются «барабаном» с волновой анимацией: если в них выпала комбинация поставленной карты — удача, нет — провал. Карта остаётся в руке. Полная таблица исходов — по кнопке **«🎰 ТАБЛИЦА СТАВОК»** (на экране выбора класса — прямо на карточке Матрицы, в бою — в верхней панели, где у военного «ПЕРЕГРЕВ»); окно не закрывается само — только крестиком/Esc. Кратко:
  - **2 бита** — удача: первое перемещение за ход проходит сквозь стены, мины и объекты (финиш — только на свободной целой клетке); провал: мощность падает в 0, экран перезагрузки, слоты сгорают и ход немедленно заканчивается (к следующему ходу мощность восстанавливается по обычным правилам).
  - **3 бита** — удача: поставленная карта один раз закрывает слоты через закрытые (открытые по обе стороны от закрытых считаются соседними); провал: ваши атаки задевают и вас — половина урона (округление вверх) по себе.
  - **4 бита** — удача: первая атака за ход бьёт двойным уроном; провал: поставленная карта блокируется до конца следующего раунда.
  - **5+ бит** — удача: ДЖЕКПОТ — половина слотов становятся «идеальными» (◆, считаются и 0, и 1) и +5 слотов на этот ход, на весь экран — золотая переливающаяся надпись (тает за 1,5 с); провал: передвижения и урон программ −1 (срезанные до нуля заблокированы — и движение с дальностью 0, и атака с уроном 0).
- **Военный интерфейс** — кнопка «ПЕРЕГРЕВ» (ограничений нет, хоть каждый ход). Незакрытые обычные слоты под перегревом дают +мощность на следующий ход, но бонусные слоты приходят **ПЕРЕГРЕТЫМИ** (оранжевые полосатые): живут один ход, каждый незакрытый бьёт на 2, а повторный перегрев их не учитывает.
- **Боевой лог** пишется в чат (пометка `//ЛОГ`): удары, отключения, очки захвата, карантин антивируса. Действия игрока под Инкогнито не логируются — даже его убийства безымянны. Защитные программы в лог не пишутся. Кольца защит и метки статусов видит только их владелец.
- **Змейка.** Если ваш ход не наступает дольше 2 минут, игра предложит змейку в отдельном окошке (стрелки/WASD, на телефоне — свайпы по полю; окно таскается за заголовок); при возврате вашего хода окно мигает. После смерти показывается ваш счёт и **топ-3 игроков за сессию** (у каждого игрока — одна строка: повторная партия обновляет её, только если побит личный рекорд, так что весь топ нельзя «захватить» серией игр). Набрали 20 очков — еда может появиться **красной** (шанс 5%): съев красный пиксель, вы «вламываетесь» в змейку случайного игрока в комнате — начинается **PvP на общем поле** (у каждого своя змейка; столкновение со стеной или любой змейкой — смерть). PvP цепляется **только к тем, у кого змейка сейчас запущена**, и **никогда — к игроку, чей ход идёт прямо сейчас** (его партию не сбиваем); если подходящих нет — красный пиксель просто рассеивается.
- **Дальность программ** считается по Манхэттену (только 4 направления, без диагоналей) — как передвижение. **Подсветка на карте честная:** радиус атаки показывает только клетки в линии видимости (клетки за битыми пикселями не светятся — туда всё равно не достать; исключение — программы, бьющие сквозь стены), а клетки передвижения подсвечиваются по фактической достижимости с обходом препятствий.
- **Окно карты фиксированное**: вся высота между верхней панелью и слотами, ~72% ширины игровой области по центру. От количества клеток размер окна не зависит — клетки сами сжимаются, карта никогда не вылезает за рамку и не даёт скролла. Веер отцентрирован по игровой области (сайдбар учитывается).
- **Перетаскивание программы:** карта «достаётся из руки» — в веере она прячется (место сохраняется), а за курсором следует уменьшенный призрак карты. Отпустили — карта возвращается в веер. Во время драга карты веера не поднимаются при наведении (иначе поднятая карта перекрывает слоты).
- **Подсветка слотов позиционная, с центрированием:** показывает, КАКИЕ слоты закроются при броске, но НЕ подсказывает, верные ли там биты — комбинацию игрок ищет глазами, совпадение проверяется только в момент броска. Окно центрируется под курсором: для программы с нечётным числом бит курсор держат над средним слотом, с чётным — на стыке двух слотов (стыки помечаются янтарными рисками во время драга). Курсор при этом свободен — «прилипает» только подсветка; у краёв полоски окно просто упирается в край.
- **Промах мимо цели.** Ткнули в недопустимую цель при активированной программе — только предупреждение, программа остаётся активированной. Отменить активацию (вернуть слоты) — клавиша **Esc**.
- **Сломанная система**: узор из 3 битых пикселей выбирается при прицеливании — полоса ─, столбец │, диагонали ╲ ╱ или угол (4 поворота: ┌ ┐ └ ┘). Центр узора — точка клика (для углов это изгиб), при наведении видно превью.
- **0 мощности** — интерфейс «перезагружается»: вместо экрана смерти — янтарный cmd-терминал (бегущий консольный поток на фоне, окно с последовательностью загрузки BIOS и бегущим индикатором) — висит до вашего следующего хода, слоты не генерируются, ход пропускается автоматически. Мощность восстанавливается к началу вашего следующего хода. Если мощность упала в ноль ПОСРЕДИ вашего хода (дебаг, «ОБВАЛ СЕТИ» по себе, критический провал ставки Матрицы) — ход тут же завершается сам (слоты сгорают без урона), ожидать не придётся.

## 3.5 Особые программы и защиты

Лечащие программы выделены отдельным классом **«поддержка»** (розовый принт ✚). Новые программы:

- **Разделение сигнала** (1100) — цифровая копия в радиусе 3 клеток, 7 ХП. Ставится только на свободную проходимую клетку. Объект под копией (зона, портал, мина) НЕ уничтожается: мина взрывается, портал телепортирует, эффекты зон копия не получает. Копию можно атаковать (умирает при 0 ХП и вместе с владельцем). **Для остальных игроков копия неотличима от вас** — только владелец видит, кто клон. Карта перемещения, разыгранная по своей копии, меняет вас местами. Максимум одна копия.
- **Торрент** (0110) — до вашего следующего хода: чужая программа, чей эффект вас заденет (урон, кража мощности, отталкивание, лечение — точечно или по площади), действует на вас как обычно, но вы получаете **+мощность, равную её потреблению**. Розыгрыши стакаются: каждый даёт одно срабатывание; несработавшие сгорают в начале вашего следующего хода. Свои программы, мины и зоны бонуса не дают; если эффект поглотила защита — Торрент не тратится. Голубое кольцо видит только владелец.
- **Data_Error** (10110) — куб битых пикселей 4×4 с центром в точке клика, в радиусе 10, на 2 раунда. Поверх объектов не ставится. Игроки внутри получают 5 урона и выталкиваются на ближайшую свободную клетку; защиты блокируют урон, но не выталкивание.
- **peer-to-peer** (101) — подключение к игроку в радиусе 7: до конца вашего хода ваши программы исполняются С ПОЗИЦИИ подключённого — цели и клетки выбираете вы сами (кликом по карте, как обычно), но дальность и видимость считаются от его пешки, лечение/бонусы достаются ему, а карты передвижения двигают его. Конец вашего хода разрывает связь. Щиты цели мешают подключению: брандмауэр сгорает, но связь не устанавливается, а AI-защита глушит попытку, не расходуясь (и пишет насмешку в чат).
- **Домашнее подключение** (11) — лечит игрока в радиусе 3 на 2 ХП, сквозь стены.
- **Андервольтинг** (0010) — вылечить X ХП сейчас, пожертвовав X мощности на свой СЛЕДУЮЩИЙ ход (слотов будет меньше, потом мощность вернётся). X выбирается окном 1–5, но не больше текущей мощности. Технически: жертва копится в `statuses.undervoltPenalty` и применяется в `endTurn` ПОСЛЕ сброса `powerDelta` — иначе сброс обнуляет минус в конце того же хода, и обмен бесплатный.
- **Пинг-понг** (1001) — толкает врага из соседней клетки на 4 клетки назад; останавливается о стены, объекты, игроков и край карты. Урона нет, но если оттолкнутый **пролетел сквозь мину** — она взрывается как обычно.
- **Сканер сети** (001) — показывает вам (и только вам) руку игрока в радиусе 5 сквозь стены: названия программ и какие сломаны. Прямо из окна можно **ПЕРЕХВАТИТЬ** одну целую карту: если ваши открытые слоты покрывают её потребление — она блокируется у врага до конца следующего раунда, а вы тут же разыгрываете её копию со своих слотов (не разыграли — копия сгорит в конце хода). Окно сканера **само не исчезает**: закрывается крестиком / Esc / перехватом, либо с концом вашего хода. Защита от сканера: брандмауэр (сгорает) и AI-защита (глушит, не расходуясь).
- **Закладка** (010) — ставит мину (5 урона) на свободную клетку в радиусе 3 (на клетку с игроком — нельзя). Для врага она неотличима от хозяйской.

Изменения старых программ:

- **Проход сквозь баги** — потребление 111 (было 10).
- **Режим Насилия** — потребление 110 (было 00110).
- **Брандмауэр** — видимое янтарное кольцо вокруг пешки; блокирует негативные эффекты, включая выкачивание мощности, толчок и сканер сети. Розыгрыши стакаются (2 брандмауэра — 2 блока, метка в очереди показывает число: FW×2); несгоревшие блоки пропадают в начале вашего следующего хода.
- **Инкогнито** — точечные программы не захватывают игрока в инкогнито: его нельзя выбрать целью. Программы по площади и окружению действуют на невидимых в полную силу.
- **АИ защита** — фиолетовое кольцо; блокирует вообще всё внешнее, даже помощь (лечение союзника, лечебные зоны). При срабатывании — окно ИИ с фразой, при блоке в чат пишет насмешку от ИИ-бота. Имя бота закрепляется на одну активацию: весь раунд он пишет под одним именем, при следующей активации имя новое. Срабатывает раз в раунд: на вторую попытку ИИ «ревнует» и блок не происходит.
- **Военный интерфейс** — пока активен перегрев, экран слегка «лагает» (плывёт и мылится).

## 3.6 Админ (хост): кик и переподключение

- **Кик.** Хост (первый вошедший в лобби) — админ сессии: он может исключить игрока кнопкой **✕** в списке игроков (в лобби и в матче) или командой чата `/kick позывной` (регистр не важен). Кикнутый видит сообщение и вылетает на экран входа; его позывной попадает в «чёрный список» — повторный вход с ним закрыт, пока все не вернутся в лобби. Себя кикнуть нельзя. Если игрока кикнули посреди матча, его пешка остаётся на поле (как при обычном выходе).
- **Переподключение.** Вылетевший посреди матча игрок (разрыв связи, закрытая вкладка) может зайти снова **под тем же позывным** — сервер узнаёт его персонажа и возвращает руку, ХП, мощность и место в очереди. В чат при этом пишется служебное сообщение.

## 3.7 Антивирус

Антизатыш-механика против затянувшихся матчей: через N раундов (задаётся в лобби, 0 = выключен, по умолчанию 5) просыпается **АНТИВИРУС** — общий враг всех игроков. Тип выбирает хост в лобби (по умолчанию «случайный» — узнаёте при пробуждении):

- **ПЕРЕСБОРКА КАРТЫ** — один раз перетасовывает битые пиксели и мины. Проходимость гарантируется (проверка BFS: игроки и точки контроля связаны), точки не трогаются.
- **ПЕРЕГРУЗКА СЕТИ** — каждый раунд всем живым −1 ХП (урон среды, защиты не глушат).
- **КАРАНТИН ПРОГРАММ** — при пробуждении и далее каждые 2 раунда у каждого сгорает случайная программа из руки (что именно — пишется в лог).
- **ПРЫЖКИ УЗЛОВ** — при пробуждении разбрасывает всех, дальше каждый раунд телепортирует одного случайного игрока.

В верхней панели — индикатор: до пробуждения обратный отсчёт, после — красная метка с типом.

## 4. Музыка и новости

- В сайдбаре — компактная строка радио. Кнопка **📻 РАДИО** открывает отдельное окно: переносится **только за заголовок**, размер меняется **уголком в правом нижнем углу**. В нём: управление, громкость, плейлист, загрузка треков. Окно прячется, пока идёт загрузка партии, а **музыка останавливается, когда матч заканчивается**.
- Кнопка «ЗАГРУЗИТЬ ТРЕК» — mp3/ogg/wav/m4a/flac/opus/webm/aac (до 80 МБ) улетает на сервер и слышен всем. Кнопка **✕** у трека в плейлисте удаляет его с сервера. Длинные названия треков ползут бегущей строкой.
- Управление (play/pause/следующий/перемотка) — **своё у каждой комнаты**: две параллельные партии слушают разное и друг другу не мешают. Громкость — у каждого игрока своя. Ползунок громкости работает по квадратичной кривой (как слышит ухо): крайнее левое положение — полная тишина.
- **Новости:** положите свои аудиофайлы в папку `news/` рядом с сервером. Примерно раз в 2 минуты музыка приглушается и поверх, с радиопомехами, играет случайная новость.
- Загруженная музыка хранится в папке `music/`.

## 6. Принятые упрощения (можно изменить)

- Передвижение — только по 4 сторонам (без диагоналей).
- Дистанции атак/эффектов считаются по Манхэттену (ромб, только 4 направления — как передвижение).
- Атаки блокируются битыми пикселями по прямой линии видимости.
- «Режим Насилия» действует до конца текущего хода.
- «Сторонний айпи» действует до конца текущего хода: урона от незакрытых слотов нет, а выбранный при активации игрок (только из числа ближайших — при равной дистанции выбираете сами кликом) получает +мощность, равную числу незакрытых слотов, на свой следующий ход. Анти-накопление: если у цели в руке есть свой «Сторонний айпи», он блокируется до конца её следующего хода — цепочки «бонус → ещё больший бонус» разрываются.
- Игрок, вышедший посреди матча, остаётся на поле — его ходы завершает таймер. Зашедший заново под тем же позывным получает своего персонажа обратно (см. 3.6).
- В командном режиме дружественный огонь включён: союзник — тоже легальная цель.
- Копия «Разделения сигнала» хранится отдельным оверлеем поверх объектов карты (`state.copies`), поэтому зона/портал/мина под ней не стираются. Она занимает клетку, активирует мины и порталы, но эффекты зон на неё не действуют. Атаковать её может любой урон по врагу, защиты владельца на неё не распространяются.
- Эффект зоны (лечение/урон/мощность) применяется в начале хода ДО истечения защит — поэтому «АИ защита» успевает заблокировать даже лечебную зону.
- Парные телепорты связываются номером пары (задаётся в параметрах объекта): каждый номер обязан быть ровно на двух порталах — это проверяется при «КАРТА ГОТОВА». Выход из пары — случайная свободная клетка в радиусе 1 вокруг второго портала; если свободных нет, телепортация отменяется с ошибкой, игрок остаётся на месте, а слоты, потраченные на программу передвижения, возвращаются (открываются обратно).
